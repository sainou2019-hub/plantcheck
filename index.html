Firebase ドメイン許可が必要です

GitHub Pages（sainou2019-hub.github.io）からのGoogleログインを許可するために、Firebase Consoleでのドメイン追加設定が必要です。

【設定手順 (1分で完了)】

  1. Firebase Console を開く
  2. Authentication > 設定 (Settings) > 承認済みドメイン を開く
  3. 「ドメインの追加」に以下の文字列を貼り付けて保存:
sainou2019-hub.github.io
